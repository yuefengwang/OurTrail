# Cloud Field 显示窗自适应 · 证据包（2026-10-09 续轮）

分支 `win/weather-v2-cloud-position`，本轮基线 `bedfeed`（上一轮「云层位置语义统一」的提交）。
本轮只做一件事：**剖面显示窗从固定 2000–6000 m 改成由有效数据 + 有效云层 + 查询点决定**，
并给装不下的部分加上不误导的边界说明。判读、天象条件、云函数一律未改。

## 根因（一句话）与实测数字

固定窗 2000–6000 m 同时被三件事共用：等值带网格与裁切、「这张图画哪一段」、OI 沿海拔找云层的扫描范围。
第一/第二件用固定窗时，**「云整扇在窗外」与「确认晴空」画出来一模一样**：

| 样本 | 旧：云行墨迹 | 新：窗 | 新：墨迹 | 判读（前后一致） |
|---|---|---|---|---|
| 云 900–1700 m，点 4,058 m | **0 环 / 0 px²** | 1,250–4,250 m | 4 环 / 25,011 px² | ok → ok |
| 云 6,100–6,400 m，点 4,058 m | **0 环 / 0 px²** | 4,000–6,500 m | 4 环 / 28,435 px² | mid → mid |
| 云 1,700–2,400 m，点 3,004 m | 5 环 / 30,730 px²（被切断） | 1,500–3,250 m | 5 环 / 132,173 px²（完整） | ok → ok |
| 确认晴空 | 0 环 / 0 px² | 2,750–4,250 m | 0 环 + 图上印「实测高度范围内没有有意义云量」 | clear → clear |

真实数据侧：本轮快照（`tools/real-cloud.json`，fetchedAt 2026-10-09T06:04Z）24 h × 3 地点里，
固定窗下有 **11 个小时整行 0 环**，其中 **0 个小时**其实是「窗外有云被裁掉」——
即这份快照的头 24 小时里，空白都确实是晴空；把云裁没的机制只在合成样本与更长的时间窗里被真机撞到
（见下 理塘 48h 与 成都 的边注）。**不把「机制存在」说成「天天发生」。**

## 判读不变性（任务书硬要求）

`invariance.json`：3 地点 × 6 组（本点高程 measured/estimated/none、无高程、500 m、6500 m）× 24 小时
= **432 条 `inferState` 结论**，新旧版本逐字节比对（key / reason / holds / cUser / span）⇒ **0 处差异**。
另有常驻门两道（`cloud-field-geometry-test` §14、`cloud-position-test` §8）：
把 `PROFILE.MAX_SPAN / PAD_M / DECK_MIN` 改到极端 ⇒ 显示窗必须变（证明门不空转），
而判读与 OI 的条件态/机会窗口必须逐项不变（证明窗不参与判读）。

## 作废的受控场景截图（如实记录）

六种形态里「云全在窗下 / 云全在窗上 / 跨边界 / 晴空 / 缺高程 / 无云场」线上数据不保证当次出现，
于是用 `page.callMethod('applyWeather', 受控返回体, point, {})` 走真机上的**生产渲染路径**。
读数是真的（`云带在此点下方` / `云层在此点上方` / `此点海拔未知（未画参考线）` 等，见 `device-run.log`），
但截图无效：页面自身的重查在注入之后落到「暂不展示天气数字」空态，卡片不在视口里。
**因此这六种形态的视觉证据等级只有「渲染层判据 + Node 页面级判据」，不算真机像素**，
11 张图挪进 `invalid/` 不参与任何结论。

## 仍未验证

- 375 / 414 两档**真机**（本机模拟器固定 390）。这两档本轮新增了 SVG 图元级判据
  （`meteogram-readability-test` §8：云行说明文字在 375/390/414 三档都不越界、互不重叠，按字形宽度估算），
  但那不是真机像素。
- 原生 `<picker>`（节点切换）仍是 INCONCLUSIVE：B 层套件在本轮代码上跑完是
  **BUSINESS 26/0/0 PASS、UI 64 通过 / 0 失败 / 1 未验证、OVERALL INCONCLUSIVE（exit=2）**，
  唯一那 1 项就是 `<picker>` 的 tap-through（探针实测 `.wx-picker`/`picker-view` 零命中）。
  本轮未触碰该路径，**不记为通过**。
- 「缺高程」「无云场」两种形态没有真机像素（线上单点查询一定带 `pointElevation`）。
- OI 的 `cloudLayersAt` 仍只扫固定 2000–6000 m：真实快照里 **24 小时中有 2–3 小时**存在被这个范围挡掉的 ≥80% 云层。
  本轮按任务书**没有改**（改了就会动天象成立条件），登记为下一轮的候选项。
