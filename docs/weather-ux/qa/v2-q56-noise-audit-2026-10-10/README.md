### 1.3 三条不确定来源，分开计数（任务书要求）

### 1.4 一个我原本想写错、被数据拦住的结论

我最初要写「候选层不看 `elevBasis` ⇒ 它在裸奔」。**不成立**：
`estimated` 下 `CLOUD_BELOW` 的必要条件是「±600 带内没有 ≥60% 的云」+「点下方 800 m 处有浓云」，
所以能进到候选筛选的小时**净空必然 ≥ ~800 m**。实测印证：`estimated` 唯一的候选批出现在 Δ+600，
净空 793 / 816 / 996 —— 与推算一致。
⇒ **tol 是间接但真实地传到了候选层**（通过它依赖的条件态），不需要"补传"。
真正的裸露点在别处：**`measured` 的 tol=0 是一个断言，而仓库自己说这三条来源没有误差资料**
（`cloud-field-svg.js:276–277`）。候选贴线实测（`q6-grid-phase-stability.json` 的 `候选贴线情况`）：
11 个候选小时的**距净空门槛 = 9 / 11 / 16 / 18 / 18 / 19 / 124 / 196 / 221 / 306 / 424 m** ——
在有 tol 的路径上这些数字没有意义，在 tol=0 的路径上它们就是全部余量。

### 1.5 Q5 的结构性副作用（新发现，需产品知情）

`estimated` Δ0 在两份快照上 **`CLOUD_BELOW` 恒为 0 小时** ⇒

而且截断比例比上一轮报的**更高**（82–100%，不是 50–69%）；绝对数字要按本表换。

**新发现的算法缺陷（上一轮因为实现差看不见）**：把相对带的**上界夹在点海拔**会**制造假层并屏蔽真层**。
峨眉山 2026-10-10 09:00，点海拔 3,004 m，`covered = [169, 6681]`：

```
带 [2000, 6000] → [2000,2299] 厚299(被切) · [3003,4379] · [4642,4822]
                  取最高且在点下方的层 = [2000,2299]，厚 299 < 300 ⇒ INSUFFICIENT_THICKNESS（差 1 m，还是截断造成的）
带 [504, 3004]  → [1739,2299] 厚560(两端实测) · [3003,3004] 厚1(被上界切)
                  below 里最后一个 = [3003,3004]，净空 0 < 200 ⇒ 拒 —— 真层被这 1 m 的假层挡掉
带 [504, 6000]  → [1739,2299] 厚560 · [3003,4379] · [4642,4822]
                  below 里最后一个 = [1739,2299]，净空 705、厚 560 ⇒ 候选 ✓
```

⇒ 两条设计约束（都是实测，不是偏好）：
1. **相对带的上界必须高于查询点**（收到 `covered.hi` 或 `ALT1`），否则会在点海拔处造出一层
   `top = 点` 的夹断薄层；`detectCloudSeaCandidates:273` 的 `below[below.length - 1]`
   按 base 排序取最后一个，会优先选中这层薄皮，从而**屏蔽真正的候选层**。
2. 顺带暴露同一行的脆弱性：**任何**恰好结束在点下方的薄层都会顶掉下方厚层。
   这条属算法类，与 R1 换带耦合，应写进 R1 的实施验收（本轮不修）。

## 3. 任务二(续) · 四个治理方向的比较（只分析，不选型）

| 方向 | 隐含假设 | 在这份数据上能消掉什么 | 消不掉什么 / 风险 | 该怎么测 |
|---|---|---|---|---|
| **① 连续插值**（不再按 50 m 格点判 ≥80%，改在高度上解阈值） | 现在的误差主要来自"格点太粗" | **实测收益 ≈ 0**：E1 已经是 0 m。代价是每小时 4,001 次采样 vs 81 次 | 不解决 E3；若改成"对整段积分"会**改变候选集合**，属业务判据改动，越出本轮边界 | 先测收益再谈实施：对 1 m 参照的偏差已 = 0 ⇒ **不建议作为治理项** |
| **② 固定统一网格**（把带下沿量化到全局 50 m 格） | 相位噪声来自"每个点用自己的下沿" | 预防性收益：今天 `ALT0` 是常量 ⇒ 相位恒定（实测候选级翻转 0）。**R1 一旦改成相对带，下沿就随点漂移，相位噪声会被 R1 引进来** | 量化到 50 m 会让带边界最多偏移 25 m，需确认这 25 m 不改变 `covered` 判定；**并且必须同时约束上界**——§2.4 实测：上界夹到点海拔会制造假层、屏蔽真候选 | 用本目录探针在"相对带"下重跑 50 相位，比较量化前后的**候选级**翻转率（本轮未做，属 R1 前置实验） |
| **③ 边界不确定状态**（层被切或判定随相位变化时，显式给"不确定"） | 不确定应当成为输出的一部分而不是被阈值吃掉 | 与 R2 的 `baseBoundary/topBoundary` 天然对接：被切层已经逐个有名有姓 | 若由"相位扫描"驱动，会**为 0 个候选级翻转而弃权 20 个被切小时**——代价远大于收益 | 判据应挂在 E3（截断）与 §1.4 的"余量 vs tol"上，而不是挂在 E2 上 |
| **④ 敏感区间标记**（把"距门槛 < 已知输入噪声"的结论标出来） | 小余量结论需要被区别对待 | 直接命中 §1.4：候选净空余量 9–424 m，而**唯一有量化的输入噪声是 ±600 m（且只在 estimated 路径）** | **必须先回答"measured 的噪声是多少"**，否则 tol=0 ⇒ 敏感区间恒为空，这条判据永远不触发（静默假绿） | 需要一条门：给定 basis=measured 时该标记必须能触发才算它有效——本轮无法构造，因为 tol 是 0 |

**方向之间的取舍点，一句话**：E1 已被测掉，E2 在候选级为 0，
所以**真正值得治理的是 E3（截断，属 R1）与"measured 路径 tol=0"这个断言（属 Q5 口径决策）**；
①④ 在现有证据下收益为零或不可触发，②③ 的收益要在 R1 改了带之后才出现。
**本轮不选任何缓冲值**：§1.4 的 9–424 m 余量分布是"该问什么问题"的证据，不是"缓冲取多少"的答案。

## 4. 任务三 · 误差归类与实施门槛

### 4.1 哪些误差属于数据源、算法、产品口径

| 归属 | 具体项 | 本轮证据 |
|---|---|---|
| **数据源** | 模型地形高度 ±300–600 m（P2 spec `:135/:169` 自陈）；气压层 `geopotential_height` 当几何高度（未核，Q7）；22 层气压面的垂直稀疏（层间线性） | §1.3 ① 类：Δ−300 让唯一真实窗口消失 |
| **算法** | E3 截断（带的边界被当成云的边界）；相对带引入的相位漂移；**相对带上界夹到点海拔会制造假层**；`below[below.length-1]` 每小时只取一层且按 base 排序，薄层可屏蔽厚层（§2.4） | §2.3、§2.4；`候选贴线情况` 里 11 个候选有 **9 个** `该层是否被带切=true` |

### 4.2 Q5 / Q6 该不该在 R1 之前解决

**Q6：不该单独前置，但必须作为 R1 的验收项。**
理由（实测）：今天候选级相位翻转 = 0 / 888，E1 = 0 m —— 没有需要"先修"的东西。
但 R1 把带下沿改成"点的相对高度"会**逐点改变网格相位**，等于把今天不存在的 E2 引进来。
⇒ 门槛形式：**R1 的实施验收必须包含"新带形下的 50 相位候选级翻转率"**，
探针已就绪（`q6-grid-phase-stability.js` 的 `layersAt` 支持 `off` 与任意 `lo`），只是本轮没有相对带可测。

**Q5：应当先于 R1 做一次口径决策，但不需要先改代码。**
理由：R1 放宽扫描带会**增加**候选小时（实测相对带把候选从 5 提到 11–14），
而 §1.4 显示新候选的净空余量会落在 9–424 m 这个区间里（11 个候选的中位 124 m）；
如果 `measured` 的 tol=0 不被澄清，R1 等于把"发卡的依据"建在一个比自身输入断言更窄的余量上。
⇒ 需要的是**一次回答**（GPX/选点/手填的海拔算不算精确值），不是先写代码。

## 5. 真实样本影响的总结（一句话一条）

1. 888 个"地点×小时"格（216 + 672）里，生产规则下**候选级相位翻转 0 次**。
2. 50 m 步长对 1 m 参照的边界偏差**实测 0 m** —— 不存在需要治理的离散化误差。
3. 海拔挪 ±300 m 会让**唯一那个真实云海窗口从有到无**（measured 路径，4 站快照）。
4. `estimated` 路径在名义海拔上**672 小时里 0 小时**给出 `CLOUD_BELOW`；78 小时因 ±600 误差带弃权。
5. 11 个候选小时的净空余量落在 **9–424 m**（中位 124 m），其中 **9 个**所在层被扫描带切过。
6. 云底极差中位 49 m 的相位噪声**100% 来自被切层**，而这批小时 R2 已经逐个标出来了。
7. 用生产规则重测后，现状候选层的截断比例是 **82–100%**（上一轮报 50–69% 是被实现差低估的）；
   而相对带若把上界夹在点海拔，会**制造 1 m 假层并屏蔽真候选**（实测 1 小时，§2.4）。
