## 本轮验证中修正的问题

1. 新增“最近查询”后，一个可选字段曾被赋为 `undefined`，宿主状态保存会拒绝，表现为 UI 已切换而保存状态停在旧计划。改为明确 `null`，用回到原计划的点击流程复验。
2. 保存列表与最近查询可能展示同一地点名称，旧断言误把两处都计为收藏。改为在实际“主动保存”面板内检查，仍要求唯一一项，不以放宽数量代替验证。
3. 嵌入环境不允许原型直接下载 Blob 文件，因此原文件演示改为只读查看和逐字节核对；未宣称提供下载或持久存档。
4. 长时窗收紧时间刻度数量，预报末端禁用超出可用长度的时窗；不靠缩小轴字解决拥挤。
