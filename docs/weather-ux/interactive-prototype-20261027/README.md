# 天气交互原型 · 2026-10-27

本目录用于产品与开发协作审阅，演示天气查询、云层剖面和个人徒步行程的交互，**不代表小程序功能已经上线**。本次没有修改 `miniprogram/` 或 `cloudfunctions/`，无需部署 `trailApi`。

## 打开方式

直接用 Chrome 或 Edge 打开本目录的 `index.html`，无需启动服务或微信开发者工具。图标和提示组件的通用脚本由 CDN 加载，完整展示需要联网；天气内容不调用真实天气接口。

默认打开示例行程的「沿途天气」。点击顶部返回按钮进入天气首页，可体验地图选点、经纬度查询、轨迹导入和已保存资产入口。

| 文件 | 用途 |
| --- | --- |
| `index.html` | 已导出的独立浏览器预览，审阅从这里开始 |
| `weather.fragment.html` | 可编辑的原型源文件 |

修改原型应编辑 `weather.fragment.html`，随后重新导出 `index.html`，不要只改生成文件。

## 已确认的产品决策

1. 首期重点是时间 × 海拔的云层剖面，不包含地图卫星云图或大范围云层动画。
2. 多日徒步按天分组，用户可手动设置关键节点的预计抵达时间；计划时间不修改原始 GPX 记录。
3. 目标方案为登录后云端同步、同时保留本机缓存；本原型只模拟登录与云同步流程。
4. 天气与活动共用路线库，但天气行程单独保存，区分路线资产与具体出行计划。
5. 打开轨迹或行程默认展示「沿途天气」，点击节点后查看逐时预报、云层剖面和日月天相。
6. 从活动带入路线和出发时间后，形成个人独立天气计划，修改不回写活动。

## 建议审阅路径

- **沿途天气**：切换 D1 / D2，查看节点预计抵达时刻；进入节点后切换逐时、云层和日月天相。
- **云层剖面**：切换 24 / 48 / 72 小时，点击或拖动时间轴，检查云量、海拔参考和读数联动。
- **个人计划**：编辑日期和节点时间；同一天时间逆序时阻止保存；取消不改原计划，复制生成独立副本。
- **单点查询**：返回首页，地图选点或手动输入经纬度；单点不显示「沿途天气」，可加入常用地点。
- **路线导入**：使用示例轨迹或选择本机 GPX；导入后未安排的节点不虚构抵达时间，原有路线、计划与收藏保留。
- **资产管理**：分别查看常用地点、共用路线和个人天气计划，核对三者的归属与入口。

视觉采用当前活动页的森林绿与冷白纸面方向。原型的图表和布局用于确认信息层级、交互与可读性，不是小程序组件的直接替代品。

## 演示边界

- 天气、云层和日月天相均为**样例数据**，不是实时预报，不能作为出行决策依据；样例日期不会随实际日期自动滚动。
- 地图选点是交互模拟，没有真实地图 SDK、搜索、定位或坐标转换服务。
- 登录、云同步、共用路线库与活动导入展示的是目标流程，没有接入真实账户、数据库、活动或路线 API。浏览器的演示状态保存不等于生产级离线缓存或跨设备同步。
- GPX 仅在本机读取，文件须小于 2 MB，最多抽样 6 个点作交互预览；不上传文件，不完整存档，不处理完整轨迹高程、里程或分段业务。
- 缺海拔时不画地点海拔参考线；云层缺测时明确提示且不补画云；超预报范围隐藏预报；离线状态标为缓存演示。缺测与离线分支由验证脚本注入演示状态，不是实际网络故障结果。
- 验证范围是浏览器原型，不包含微信真机验收、真实天气精度、云同步与活动权限验证。

## 运行检查

在已有 Node.js、Playwright 及其 Chromium 的环境中，从仓库根目录运行：

```sh
node docs/weather-ux/interactive-prototype-20261027/verify.cjs
node tools/check.js
node tools/check-handlers.js
git diff --check
```

不要为本原型向项目添加 `package.json`、锁文件或 `node_modules`。可复用仓库外的 Playwright 安装，并通过环境变量指定路径：

```sh
PLAYWRIGHT_MODULE_PATH="/absolute/path/to/node_modules/playwright" \
CHROME_EXECUTABLE_PATH="/absolute/path/to/chrome" \
node docs/weather-ux/interactive-prototype-20261027/verify.cjs
```

`PLAYWRIGHT_MODULE_PATH` 和 `CHROME_EXECUTABLE_PATH` 均可省略；省略时使用 Node.js 默认模块解析和 Playwright 默认 Chromium。截图默认写入系统临时目录，可通过 `WEATHER_QA_OUTPUT` 指定仓库外的输出目录。脚本失败时退出码为非零，成功时打印实际检查数与截图路径。

覆盖内容包括默认沿途入口、节点与图表切换、读数联动、320 / 375 / 390 / 414 px 布局、标签碰撞、预报范围、时间校验、独立复制、收藏与导入保留、缺海拔/缺云层/离线状态以及浏览器运行时错误。

2026-10-27 对本目录导出的 `index.html` 实测：**29 项浏览器检查全部通过**，浏览器运行时错误为 0；`tools/check.js` 通过，`tools/check-handlers.js` 通过（既有未使用 handler 1 条未增加）。这些结果仅覆盖上述原型与静态检查，不等于生产功能或微信真机验收。
