## 4. 真机抓到的三个缺陷（都不是静态门能看见的）

| # | 现象 | 根因 | 修法 | 门 |
|---|---|---|---|---|
| 1 | 「先看条件」等于没做到：strip 底边压在折线上（余 0.2px），区头整块在折线下 113px | 页首前导区 631px，其中**点卡 226px** 在重复导航栏已给出的身份 | 点卡下移到图正上方（图上那根虚线就是这里的海拔），收成两行：名称+存入入口 / `坐标 … · 海拔 …` | `page2-gates §5b` 3 条（不再早于 strip、在 7 日条之后图之前、四项事实+入口各 1 个）+ 驱动读数 `pointMeta top 991.7` |
| 2 | 「★★☆☆☆条件较差」贴成一串 | `.cond-grade` 是 `<text>`；**微信的 text 不能当 flex 容器**，`gap:6px` 被静默丢弃（同页 `.cond-pill` 是 view，间隙正常） | 容器改 `<view>`，星串与评级仍是两个节点 | `page2-gates §5b` 2 条（容器 tag=view、两个独立节点）+ 驱动 gap=6。变异：改回 `<text>` ⇒ 1 红 |
| 3 | 「全图展示」被排成一条居中文字（像副标题），且按钮右缘落在 319 而非 370 | ① 页级 `.section-head` 只写了 display/align/justify，**没复位 app.wxss 的 `flex-direction: column`**；② `<button>` 的 UA 默认宽 184px + 左右 `auto` 外边距，在 flex 行里先吸掉剩余空间 ⇒ 居中漂浮 | 只给带行动的区头加 `.has-action`（row + wrap，来源行 `flex-basis:100%`），按钮收成内容宽度、无外边距；另两个区头保持竖排 | `page2-gates §5b` 2 条（层叠终值：带行动=row@页级、另两个=column）+ 驱动 3 条读数（同一基线、贴右、来源单行）。变异：`.has-action` 改回 column ⇒ 1 红；给「天相详解」挂 has-action ⇒ 1 红 |

三条修法都**没有新增色值/字号**：`.point-meta` 用既有 `--text-caption`/`--muted`，其余全复用既有类。
