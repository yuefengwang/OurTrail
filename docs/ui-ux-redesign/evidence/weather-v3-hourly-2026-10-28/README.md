## 两个探针缺陷（不是产品回归，当场修正后复跑转绿）

1. 首次 34/1：带内数字的 y 断言写死 244–261（只对高云行成立），中云/低云在 276/296 ⇒ 改为按行取 `top+12`。
2. 对比度断言第一版只比了 3 个数字：`<stop>` 的 `offset` 是 **0–1 的相对值**，不是绝对 x，绝大多数数字因「最近 stop 距离超过半列」被跳过。改为 `x1 + offset × (x2 − x1)` 后 24/24 全部参与比较。**这一版才是有效的**，前一版属假绿。

## 真机抓到的一个产品缺陷

`50%` 用 `flex:1` 居中时，中间格拿到的是**两端标签之间的剩余空间**（`0%` 宽 12 / `100%` 宽 22），中心落在 123.2px 而不是色带中点 128px —— 即「补了 50% 中点」这句在几何上不成立。
改成 `position:absolute; left:50%; translateX(-50%)` 后实测 127.965px；structure 门加了两条静态判据（容器等宽 + 中间格 50% 定位、且不得写回 `flex:1`）。
改前的 5 张滚动帧已隔离到 `invalid/`。
