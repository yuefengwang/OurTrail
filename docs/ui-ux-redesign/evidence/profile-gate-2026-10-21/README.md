## 行为说明

- 浏览链路不变：发现/活动详情不要求先补资料。
- 报名页与编辑器在检测到档案缺少姓名/手机号时，**不再跳「我的」**，而是在本页自动弹出资料 sheet。
- 微信头像/昵称/手机号都必须由用户真实点击 `chooseAvatar` / `nickname` / `getPhoneNumber` 触发；`getUserProfile` 已不保证返回真实头像昵称，因此没有用它做“静默登录”。
- 保存走 `profile.save` + CAS；保留档案里的紧急联系人、医疗备注与已有头像；保存成功后报名页重读、编辑器自动继续刚才的保存/发布。
- 手机号授权失败/取消时可手填，不阻塞报名。
