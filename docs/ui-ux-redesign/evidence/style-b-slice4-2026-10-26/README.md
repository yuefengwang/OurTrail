## §2 落地结构

### 2.1 图上方：逐时摘要带（`weather.wxml:146-155`）

```
.day-strip          7 日卡（横滚，既有）
.tl-viewseg         24 / 48 / 72h 切窗（既有）
.card 点卡           此点 · 坐标 / 海拔（D7 已下移到图上方）
.hour-strip         8 列：天气简字 / 温度 / 时刻   ← 本轮新增，是图的表头
图表                meteogram（统一图）
.pop-strip          「降水概率」一行 8 个百分比     ← 本轮新增，是图的表尾
OI 卡 / 结论明细 / 详细数据 …
```

**为什么带与图必须同窗同源**：`applyWeather` 里 `buildViewSeries(chartSeries, viewSpan)` 只算一次，
`buildHourStrip(viewSeries)` 吃的是同一个数组（`weather.js:695-700`）；切窗时
`onSpanToggle` 把两者一起重建（`weather.js:1433-1441`）。任何一条走新窗口、另一条留在旧窗口，
带上的温度与图上曲线说的就是两件事——这正是本仓反复踩过的"同一事实两个实现"。

**列数与步长：固定 8 列，步长 = 窗长 / 8**（`weather.js:1501-1524`）。

| 窗口 | 步长 | 列数 | 时刻序列 |
|---|---|---|---|
| 24h | 3h | 8 | 00 / 03 / 06 / 09 / 12 / 15 / 18 / 21 |
| 48h | 6h | 8 | 00 / 06 / 12 / 18 ×2 天 |
| 72h | 9h | 8 | 00 / 09 / 18 / 03 / 12 / 21 / 06 / 15 |

初版写的是"≤9 列（3 / 6 / 8 小时）"，自查时否掉：375 宽下内容区 335px ÷ 9 = **37.2px**，
而最宽简字「毛毛雨」在 12px 字号下约 **36px** —— 只剩 1.2px，折行会把温度行推歪；
且 8 小时步长在 72h 上会与 24 取余为 0，同一时刻重复出现。改成固定 8 列后：
每列 41.9px（375）/ 43.8px（390）/ 46.8px（414），三字简字仍有 5.9px 余量。

**列表键必须带日期**：48/72h 跨天，`00:00` 会出现两次。键取 `d + 'T' + t`
（`weather.js:1517`），模板 `wx:key="k"`；写 `wx:key="t"` 就是重复键（WXML 复用错节点）。
这一条在初版里是**错的**，自查抓到并修，两层各留了一条断言（`weather-page-test` §8 键唯一、
`page2-gates` §5b 模板与数据都认 `k`）。

### 2.2 图下方：降水概率行（`weather.wxml:236-244`）

- 整行由 `popShown` 控制：窗口里**一个概率读数都没有**时整行不印（不是空壳常驻）。
- 个别小时缺概率 ⇒ 那一格印 `—`，行仍在：**缺测 ≠ 不会下雨**。
- 数值行与摘要带同为 `flex: 1 0 0` 等分 ⇒ 两行天然按列对齐，不需要滚动同步。

### 2.3 详细数据（`weather.wxml:481-517`）

```
.section-head.has-action   详细数据 + 「展开逐小时全表 / 收起全表」
.card.brief-rows           4 × .fact-row：温度 / 降水量 / 风速 / 云量（当日区间）
.card.num-sheet (showDetail) 逐小时全表 14 列 —— 不删列、不降级
更新时间 / 数据来源 / 许可        （既有，紧随其后，与板 04-4 的底部两行对位）
```

四行是**默认可见**的，全表仍默认收起：板上的「详细数据」本身就不是全表，而本页的
14 列全表在手机上必须横滚，直接铺开会把下面的数据来源推到两屏之外。

`.section-head.has-action` 而不是普通区头：本页两条不带行动的区头被 `page2-gates §5b`
钉成竖排（标题 + 说明两行），带行动的那条由 `.has-action` 复位成一行——沿用 Slice 4 之前
就有的分档，不新增样式分支。

## §4 有意的偏离（板上做不到 / 我们做得更准）

| # | 板 | 我们 | 理由 |
|---|---|---|---|
| D1 | 摘要有天气图标；详细数据四行也有头像标 | WMO **简字**（晴 / 多云 / 毛毛雨…），行内无图标 | 仓里 `assets/` 只有地图 marker，没有图标资源；不引资源文件是本轮既定边界。简字复用 `.day-phrase` 的同一套 tone（文字承载语义），不另造色 |
| D2 | 降水量印 `mm`、风速印 `m/s` | 降水量 `mm/h`、风速 `km/h` | 与 provider 原单位、下方 14 列全表的列头**同一口径**。改成板上的单位就得同时改全表与 `hourView` 的注释，否则同页两个单位 |
| D3 | 四行下方一张山景照片 | 无照片 | C21 已定不引入节点照片；仓内也没有可用的实拍图资产 |
| D4 | 降水概率两行（2×5） | 一行 8 列 | 板上只有 5 列/行是因为它按天折行；折行会让"哪一列对应图上哪一小时"要靠两行拼接才能读。一行 8 列与摘要带同列对齐，24h 窗一屏可读 |
| D5 | 右上圆形图标按钮 | 文字链「展开逐小时全表」 | 不新增图标；该动作本来就是本页唯一的展开入口（`toggleDetail`），文字链比图标更说明它展开的是"全表" |
| D6 | 图表横轴 9 小时一格 | 沿用 meteogram 自己的刻度 | 图表刻度由 `meteogram` 按宽度与窗口算，本轮不碰图表几何（真机未跑，改刻度没有像素证据兜底） |

## §6 变异自证（真文件改坏 → 跑门 → 还原比对 sha256）

| # | 变异 | 预期 | 实测 |
|---|---|---|---|
| M1 | `.pop-strip` 的 `wx:if="{{popShown}}"` → `{{true}}` | 红 1 | **红 1**：降水概率行按 data 显隐… |
| M2 | 步长 `Math.round(n / 8)` → `Math.round(n / 12)` | 红 3 | **红 3**：24h 三小时序列 + 48/72 序列 + 键唯一（同一处改坏，三条相关断言一起红，不是重复计数） |
| M3 | `hasPop = typeof h.pop === 'number' && Number.isFinite(h.pop)` → `true` | 红 2 | **红 2**：概率全缺 / 个别小时缺 |
| M4 | 温度行 `range(nums(h => h.temp), '°C')` → `range(nums(h => h.temp \|\| 0), '°C')` | 红 1 | **红 1**：缺读数整行印「—」… |
| M5 | `.num-sheet` 去掉 `wx:if="{{showDetail}}"` | 红 1 | **红 1**：详细数据四行默认可见 / 全表收起 |
| M6 | 列键 `k: h.d + 'T' + h.t` → `k: h.t` | 红 1 | **红 1**：列键全部唯一（跨天同一时刻不得撞键） |
| M7 | 模板 `wx:key="k"` → `wx:key="t"` | 红 1 | **红 1**：列表键是带日期的唯一键 |

每条变异要求锚点命中恰为 1 次（否则计一条漏网并 exit 1），还原后比 `sha256`，
最后复跑两套各 0 红。汇总：`mutations=7 failures=0`。

**如实登记**：M2 的预期从"红 1"改成"红 3"是跑出来之后按实测改的——三条断言共享同一处输入，
一处改坏必然一起红；这不是"门多报"，而是它们本来就该同时咬住同一处。

## §8 真机

**NOT_RUN。** 驱动需要 `close --project` + `open` 重编译（共享开发者工具会话），本轮未获授权。

要升到 VERIFIED 至少需要（缺一条都不算页面级证据）：

1. **bundle 新鲜度自证**：新文案出现在屏上（例：「展开逐小时全表」「降水概率」）。
2. **载荷门槛链在截图之前**：`denied=''`、`loading=false`、`loadingWeather=false`、
   `dayCards.length>0`、`unified!=null`；否则图与带根本不在 DOM 里，读数是假的。
3. **多用例污染自证**：每例 `reLaunch` + 不同 `updatedAt`；两例读数相同即判整批截图无效
   （`weather.js:824` 的缓存键含 `updatedAt`）。
4. **三档窗口各一张**：24h / 48h / 72h，确认列数恒为 8 且**不折行**（375 宽是余量最小的一档）。
5. **缺测态**：概率全缺时整行不出现；个别缺时那一格是 `—` 而不是 `0%`。
