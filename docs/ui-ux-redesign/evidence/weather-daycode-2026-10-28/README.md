## 三条判据

1. **日卡读的是 `dayCode`，不是 `days[].code`**：7 天里 5 天 provider 码仍是 45，日卡一个「雾」都没有。
   这同时是 **bundle 新鲜度自证**——旧客户端读 `day.code`，同一份数据会渲染 5 张「雾」。
2. **夜间逐时不动**：`.hour-strip__item` 的 00:00 / 03:00 仍显示「雾」，与 provider 逐时事实一致。
3. **入云提示不再凭空出现**：这几小时的雾没有一个通过 RH≥90 + 能见度<1 km，页面上没有「此点可能入云（雾）」；
   `CALLOUTS` 里只剩那条概率免责声明。
