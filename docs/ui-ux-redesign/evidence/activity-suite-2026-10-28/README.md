## 实际验证内容

活动驱动 `tools/verify-activity-suite-native.cjs`：

- 活动首页 → 发现 → 指定活动详情 → 组织者工作台，真实点击后等待目标路由并核对结果。
- 工作台的名单、分车、现场三个常驻面板切换；导航卡进入任务、新建任务弹层打开；通知发布弹层打开；车辆页切换返程；有明确授权的现场协作者进入面板。
- 报名默认不授权；点击提交后严格核对只有资料使用授权缺项；展开资料不改变授权。合法格式的样例电话避免其他必填校验掩盖授权测试。
- 有活动与无下一次同行两种首页状态；主/次按钮、页签和导航卡的实际高度与左右边界。
- 活动驱动的未允许操作记录为空，未捕获异常为零。几何检查只对实际存在的可见尺寸节点计数，没有元素时不制造一条通过。

编辑器驱动 `tools/verify-editor-native.cjs`：

- 原生输入、快捷时间、地图取消/返回结果、路线库空态、介绍输入、发布摘要回改、必填回跳。
- 发布意图先保存草稿再打开确认层，显示可见范围和报名政策；不自动勾选组织者参加，不实际发送发布命令。
- 编辑器草稿创建/编辑命令仅被内存桩记录，不发送真实云调用。

## 截图审查与限制

人工检查不同宽度的首页、发现、详情、工作台工具/名单、发起、报名、任务/通知弹层：主要按钮同排高度一致，所检页面无左右溢出；长表单保留纵向滚动，不能将首屏未展示的内容误判为缺失。

对照时注意：后续增加了任务、通知和现场协作者样例，不能把改前空态和改后有数据状态当成严格同数据对照。纯排版判断应对照相同页面和相同状态；报告不声称自动像素比对。

**未验证**：物理手机、软键盘遮挡、系统大字体、真实账号全流程和线上写入。模拟器交互、静态检查、几何读数、人工截图审查是不同证据；总检查数不是纯点击用例数，也不是全仓业务覆盖率。未修改云函数，无需重新部署 `trailApi`。未提交或推送。

## 复跑

依赖置于仓库外，先在开发者工具中重新编译目标项目并启用自动化。运行时指定外部 `miniprogram-automator` 路径与输出目录：

```sh
MP_AUTOMATOR_PATH=/tmp/ourtrail-editor-native-qa/node_modules/miniprogram-automator \
EXPECT_ACTIVITY_UI=1 ACTIVITY_QA_OUTPUT=/tmp/ourtrail-activity-suite/recheck \
node tools/verify-activity-suite-native.cjs

MP_AUTOMATOR_PATH=/tmp/ourtrail-editor-native-qa/node_modules/miniprogram-automator \
EDITOR_QA_OUTPUT=/tmp/ourtrail-activity-suite/editor-recheck \
node tools/verify-editor-native.cjs
```

默认自动化地址为 `ws://127.0.0.1:9427`，可用 `MP_WS_ENDPOINT` 指定实际端口。依赖或端口不存在时属于环境未就绪，不得记为通过。
