| 项 | 现状 | 证据 |

- **①封面：A（推荐）保持「封面=正文图」**，把封面槽上移并保留「默认正文首张 / 可更换」；B 独立封面上传（动 schema + 文件白名单 + 部署），收益仅是封面不必重复出现在正文里。推荐 A：服务端规则已经成立，B 的边际收益低、成本高。

**建议批次**：EDI-01/02/03 为纯客户端、零部署，可合成一批先做；EDI-04 单独立项（`schema` + `selectors` + editor + 发现范围测试 + 部署）。
