# FD-01 — discover 筛选控件触控高对齐 44px（Flash 任务卡）

## 1. 任务 ID 与唯一目标

`FD-01`。把发现页三枚筛选控件的**触控高度**从 34px 提升到既有 token 44px；不改布局结构、不改文案、不改事件。

## 2. 背景与已有证据

- 缺陷：`miniprogram/pages/discover/discover.wxss:29-31` 的 `.filter-chip { min-height: 34px; }`；三枚控件在 `discover.wxml:36-38`（筛选、最新发布、最近出发）。
- 规范：`ourtrail-ui` 规则 8（反复点击的目标 ≥44px）；token `--touch-target` 实测在 `app.wxss:67`（旧文档写的 54-55 已漂移，定位时用 `grep -n -- "--touch-target" miniprogram/app.wxss`，不要手抄行号）；night-v1 openDebt 已登记 “discover .filter-chip 命中高 34px < 44（M-07 清单未含 discover，未擅改）”。
- 现状：`.filter-row` 为横向滚动（`discover.wxss:22-28`），高度增加 10px 不改变页面横向宽度；`result-count` 用 `align-items:center` 居中，不依赖控件高度。

## 3. 允许修改的文件

- `miniprogram/pages/discover/discover.wxss`（仅 `.filter-chip` 的 `min-height` 一行）

## 4. 禁止修改

`miniprogram/pages/discover/discover.wxml`、`discover.js`、`discover.json`、`app.wxss`（全局 `.chip`/token 不改）、`components/**`、其他任何页面、`tools/**`、`cloudfunctions/**`、天气/privacy、任何文档（本卡不改证据）。

## 5. 必须保留的业务行为

- 三枚 chip 的文案、`bindtap`（`onOpenFilters/onSort`）、`data-sort`、`on` 选中态类、`hover-class="button-hover"` 全部不变。
- `.filter-row` 的横向滚动、`result-count`（`{{cards.length}} 场`）位置不变。
- 空态/加载/拒绝态、筛选行为、排序行为零改动。

## 6. 实施步骤

1. 打开 `miniprogram/pages/discover/discover.wxss`。
2. 把 `.filter-chip` 规则里的 `min-height: 34px;` 改为 `min-height: var(--touch-target);`；其余属性（`padding: 0 12px`、圆角、背景、字号、字重、inline-flex）**逐字保留**。
3. 在改动处上方保留/补充一行注释：`/* FD-01：命中高对齐 ourtrail-ui 规则 8 与 --touch-target（app.wxss:54-55）；原 34px 低于 44px 触控下限。 */`
4. 自检：`git diff --stat` 只包含这一个文件；`git diff` 只包含该一行替换与注释。
