# FH-01 — home/discover 页头两对同形规则上收（Flash 任务卡）

## 1. 任务 ID 与唯一目标

`FH-01`。把 `pages/home` 与 `pages/discover` 页头里**逐字同形的两对规则**收敛为 `app.wxss` 的两个全局类，页面只保留结构；**计算值必须完全不变**。不做卡片信息行去重（那是 FH-02，另立提交）。

## 2. 背景与已有证据

- `miniprogram/pages/home/home.wxss:16-17`：`.home-head__text`、`.home-title`。
- `miniprogram/pages/discover/discover.wxss:10-11`：`.discover-head__text`、`.discover-title`。
- 两对规则声明**逐字相同**；每个类只有一个 WXML 使用点：`home.wxml:12,14` 与 `discover.wxml:11,13`。
- `app.wxss:139` 的 `.section-head` 与文字列前三条声明相同、但**被 17 个注册页 76 处引用，禁止改动**；本任务只新增两个新类，不改 `.section-head`。
- 仓库内 `tools/**` 与 `docs/**` 对这四个旧类名**零引用**（本轮 grep 实测），因此改名不触发测试引用变更。
- 批准：D-08（允许为该项在 `app.wxss` 增加 2 个类）。

## 3. 允许修改的文件（仅此 5 个）

1. `miniprogram/app.wxss`（只新增 2 条规则，位置紧跟 `.section-head` 块之后）
2. `miniprogram/pages/home/home.wxml`（2 个 class 改名）
3. `miniprogram/pages/home/home.wxss`（删除 2 条规则，保留说明注释）

## 4. 禁止修改

`.section-head` 及其下游规则、`app.wxss` 其他任何行、`components/**`、`home.js/discover.js/json`、`home.wxss/discover.wxss` 的其他规则（含 `.activity-card__info`、`.discover-views`、`.discover-note`、`.filter-row`、`.filter-chip`、`.map-card`）、其他页面、`tools/**`、`cloudfunctions/**`、天气/privacy、任何测试与证据文档。

## 5. 必须保留的业务行为

- 页头结构不变：眉题 + 标题在左，右侧入口/视图分段不变；`home-title` 的动态文本 `{{profileName ? profileName + '，' : ''}}下一次同行` 逐字保留。
- `overflow-wrap:anywhere` 与 `min-width:0` 的窄屏兜底必须保留（长昵称不挤掉右侧控件）。
- 所有 `bindtap`、`aria-label`、`data-*` 零改动；不新增 token、不新增颜色。

## 6. 实施步骤

1. 在 `app.wxss` 的 `.section-head` 块（约 :139-140）之后插入（逐字）：
```css
/* FH-01（2026-10-23）：列表页页头文字列，home/discover 曾各存一份逐字同形规则。
   20px/28px/-0.3px 是既有计算值的搬运，不是新字阶 token；勿把 .section-head 当容器基类改。 */
.list-head__text { display: flex; flex-direction: column; gap: 2px; min-width: 0; }
.list-head__title { font-size: 20px; line-height: 28px; font-weight: 600; letter-spacing: -0.3px; color: var(--ink); overflow-wrap: anywhere; }
```
2. `home.wxml`：`class="home-head__text"` → `class="list-head__text"`；`class="home-title"` → `class="list-head__title"`。
3. `home.wxss`：删除 `.home-head__text {…}` 与 `.home-title {…}` 两行，原 N2 注释保留，并在其后补一行：
   `/* 页头文字列规则已上收 app.wxss 的 .list-head__*（FH-01）；此处不再保留第二份。 */`
4. `discover.wxml`：`class="discover-head__text"` → `class="list-head__text"`；`class="discover-title"` → `class="list-head__title"`。
5. `discover.wxss`：删除 `.discover-head__text {…}` 与 `.discover-title {…}` 两行；把第 7-8 行注释中的“第二份拷贝，同族债务待解冻后上收”改为“已上收 app.wxss 的 .list-head__*（FH-01）”，其余说明（20px/600 的设计理由、min-width:0 的作用）保留。
6. 自检：
   - `grep -rn "home-head__text\|home-title\|discover-head__text\|discover-title" miniprogram` → **0 命中**；
   - `grep -n "list-head__" miniprogram/app.wxss` → 恰 2 条规则；
   - `git diff` 逐行核对：除上述增删外无任何变化；`.section-head` 原行不动。
