## ⚠️ 风险与已接受未知

| 风险 | 影响 | 处置 / 解法点 |

| chips 在 320px 放不下 4 项 | 卡片重新变高或截断难读 | 已定优先级截断、不折行；批次一在 375/390 真机 + 320 模拟宽度截屏核对 |
| 「我组织的」从徽章降为细字后易被静默丢掉 | 归属信息消失（`home.js:120-131` 有同类事故注释） | `a20-owner-hero-test` 只钉字段值，不钉像素；批次一补一条渲染层读数（读元素文本，不读 data） |
| PV4 门口径与 13 处用法需同批改 | 漏一处＝双源或红 | 同一次提交内改完，随后复跑 `m02-class-scope-test` |
| 删页标题后「通知」只剩 tabBar 标签 | 页面失去可读位置信号 | 通知页在分区标题补回「通知」；批次一结构审查时点名检查 |
| 自定义导航避让胶囊在不同机型高度不同 | 标题被压或留白过大 | 批次一真机 390 与 375 各截一张，读数取 `getMenuButtonBoundingClientRect` |
| 吸顶锚点栏与详情页 sticky 主按钮两层叠 | 互相遮挡 | `activity.wxml` 的 sticky 区（`:352`）与锚点栏定好层级；批次一滚动截图核对 |

| 开发者工具是共享资源 | 真机通道可能被占用 | 按 `docs/e2e-mp/automation-playbook.md` 记 ENV-ABORT；未经授权不做 `cli quit` |

## 被否掉的替代方案（值得记）

- **中央 FAB**：与首页「发起活动」抢预算，且熟人圈不需要常驻创建入口。
- **发现优先首页**：OurTrail 不是活动市场，「发现他人活动」不是主页面的第一任务。
- **详情页真 tab 切换**：会把用户撰写的长文内容藏起来，与「活动介绍/费用/报名后须知」的阅读需求冲突。
- **天气深色数据舱**：参考板本身不是深色（已收回旧描述）；且 `--chart-ramp` 被 3 套门 pin，反相＝整套几何/可读性基线作废。
- **把卡片 info/status 结构化**：语义更干净，但要同时改服务端投影与多套门，收益不抵风险。
- **新增活动分类字段**：业务变更夹带进 UI 轮次，还要重新部署与回填。
