## 2. 关键判断（为什么这些是 B/C，不是 A）

- **G0/G1/G2/G3/G4/G8/G16/G18** 改变的是**页面的构图与阅读顺序**，不是换 token：hero 从「图 + 下方信息区」变成「图 + 叠标题 + 浮动卡」；事实区从列表行变成卡；时间轴从路线移入行程；操作从顶部移到底部。它们都会改变 DOM 结构与首屏层级。
- **G3/G5/G12** 引入新组件；**G5/G12** 还引入派生数据（最高海拔、用时、图标映射），但**不新增 schema 字段**。
- **G10/G28** 是阅读顺序重排，单列为 S4；本轮只登记，不偷偷做。
- **G21/G22** 是明确拒绝项；如果实施时出现价格或收藏，直接判越界。

## 4. 实施顺序与回滚点

| 切片 | 内容 | 回滚点 |
|---|---|---|
| S1 | `activity-hero` + `fact-grid`（card/stats）+ 信息卡 + 路线指标 + 事实区溶解 + 照片脚注迁移 | 单独 commit；只回滚 S1 不影响 S2/S3 |
