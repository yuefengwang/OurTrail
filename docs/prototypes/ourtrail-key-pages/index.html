比较视觉方向

查看角色视角

活动详情主操作会随角色变化。工作台只展示组织者任务，保持真实产品的权限边界。

评审重点

先看页面层级和操作路径，再看配色、卡片和文案。图表、路线图和活动数据均为视觉示意。

  • 创建：三步是否清楚，是否知道还差什么
  • 天气：结论与证据是否好读
  • 详情：当前角色的下一步是否突出
  • 工作台：待办能否直达对应任务
此原型为设计讨论稿，不会调用微信或云端能力。
