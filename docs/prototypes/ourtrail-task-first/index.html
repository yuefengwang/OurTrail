05 / 编排一次同行创建者 · 可回跳的计划编辑器

编辑活动 ··· ○
草稿 / 尚未发布

先搭好计划，
再邀请朋友。

结构草图；以下分区可展开查看字段。

01　时间与活动说明

名称、介绍、组织者说明、开始与结束时间、报名截止。结束与截止时间要能直接检查，不藏进发布弹窗。

02　路线与节点

导入 GPX / 手动添加节点。展示路线名、距离、爬升；节点名称、类型、坐标与已有高程 / 时间。允许修正导入结果。没有轨迹时不伪造路线图。

03　集合与上车点

多点列表；每点独立维护名称、详细地址、坐标和集合时间。路线节点与上车点是两类对象，不能混成一个“集合地点”。

04　名额与报名规则

人数上限、手动审核 / 自动确认、是否开放报名。待审核与已确认都占名额，候补另记。

05　风险与准备

至少一条风险，每条包含问题与应对。装备清单、费用说明、取消说明。强度可写入介绍；不凭空新增“轻松 / 中等 / 较强”的结构化字段。

发布前还要确认自己是否参加

发起活动不等于报名。参加时还需确定本人出行方式与资料使用授权。

发布前检查页的内容

分区列出缺项，点击回到具体字段。已保存云端草稿、本机未保存修改分别标注。预览不发布；发布时再次检查真实契约。此原型未实现保存与发布。

查看邀请页结构 →

从不可见的长表单，改为可扫读的计划目录。字段不删；保存与发布语义不合并。细分五区是交互提案，不增加后端实体。
