# OurTrail · 成熟应用参考原型 V2

2026-10-26。入口：[index.html](index.html)。静态 HTML/CSS/JS，无第三方依赖、无网络请求、无需安装，可直接在浏览器打开。

## 设计范围

依据 [竞品研究](../../../design-research/2026-10-26-competitors/README.md) 的推荐方向制作独立版本。保留旧原型，未修改生产小程序。

- 活动首页：日期分组、最近活动突出、组织者待办直达。
- 活动详情：文字与抽象等高线构成头部，固定顺序的路线指标，时间和集合信息优先，报名操作固定在底部。等高线仅为装饰，不代表真实路线。
- 报名流程：本人资料、出行与集合、紧急联系人分组；字段校验与同意勾选；提交后明确等待审核。
- 组织者名单：状态筛选、筛选内搜索、人员详情、通过报名与数量更新。自行前往不混同于待分车。
- 路线天气：日期与时刻联动、温度/降水同轴读数、未知海拔解释。全部天气为模拟值，不调用预测服务。

## 可点击路径

1. 首页最近活动 → 活动详情 → 报名同行 → 填写虚构资料并提交 → 等待审核 → 返回活动。
2. 首页「我组织的」 → 名单 → 搜索「周远」 → 查看资料 → 通过报名 → 切到已确认。
3. 活动详情的天气入口 → 切换日期 → 点击时间 → 查看同步读数。
4. 桌面左侧可直接切换五页；弹层可点关闭、遮罩或 Escape。

## 数据与交互边界

所有活动、身份、名单和天气均为演示数据。报名输入仅在当前表单内使用，不写本地存储，不发送服务器；审核演示只改变页面内存，刷新恢复。不要输入真实个人资料。

龙泉山是参与者场景；青城后山是发起人场景，两者是不同活动。演示只有本人报名，携伴与代填流程未展开。正式实现须保留原有服务端授权、状态工具、隐私与同意规则。

创建、个人中心、通知、分车和另一条活动的详情未展开：入口显示范围说明，不伪装为已完成的功能。忙碌/弱网/冲突/无权限等生产状态不在本次视觉原型中完整实现；此交付不能作为生产验收。

天气图表为本原型绘制的模拟读数视图，不替换生产 meteogram、云层判定、天相或时间轴。未加入无依据的概率、评级或机会承诺。未来实施仍须回接真实字段与证据。

## 浏览器验证

使用独立无头 Chrome，不操作用户浏览器会话。

- 实际点击报名并提交，观测「报名已提交」和等待审核状态。
- 名单搜索与筛选、人员资料打开、审核后从待审核消失并出现在已确认。
- 日期 + 时刻切换后，模拟降水读数更新到对应值。
- 五页 × 375/390/414 三种宽度，共 15 组页面宽度检查通过，无页面或内容区横向溢出。
- JavaScript 语法检查通过，浏览器无未捕获错误。
- 已目视检查桌面整体、详情、名单与天气截图。截图为浏览器原型，不是微信小程序或真机验收。
